# Modèle de reprise Sayrhazi (`plan.txt` cumulatif).

Chaque décision validée contient : date système réelle, sujet, décision,
raisonnement et statut `À IMPLÉMENTER` ou `INFORMATIF`. Les décisions des
autres features sont conservées ; une feature bouclée est archivée dans
`.opencode/features/<nom-stable>.md` sans écraser l'existant.
