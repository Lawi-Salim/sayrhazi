# Règles globales Sayrhazi (runtime-agnostiques).

- La configuration du projet (`sayrhazi.yaml`, section `project`) est la seule source de vérité : jamais de nom de projet en dur.
- Les noms d'affichage des agents sont configurables (`agents.*`) ; les fichiers et les rôles restent stables.
- Réponses et rapports en français, sauf demande contraire. Emojis proscrits dans le travail, tolérés en blague. Typographie française correcte exigée.
- Aucun secret, token ou mot de passe dans les rapports ni dans l'historique.
- Une tâche n'existe que par son `task_id` stable, recopié dans chaque rapport.
- Les rapports et historiques d'un projet ne sont jamais partagés entre projets.
